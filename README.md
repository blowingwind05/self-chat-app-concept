# 一个只和自己聊天的 App · 项目设想展示

这里展示一个关于随手记录、长期保存与信息整理的项目设想。标题只描述这个项目是什么，并非项目名称；相关应用功能尚待开发。

## 在线查看

- [项目设想网页](https://blowingwind05.github.io/self-chat-concept-web/) · [独立源码仓库](https://github.com/blowingwind05/self-chat-concept-web)
- [独立动画短片](https://blowingwind05.github.io/self-chat-concept-film/) · [独立源码仓库](https://github.com/blowingwind05/self-chat-concept-film)

## 本地查看

下载仓库并解压后，双击 `web/index.html` 打开完整网页。首屏的词语汇聚、滚动展示和嵌入短片均可在本地运行，无需安装依赖。

只看短片时，可以打开 [离线单文件 HTML](downloads/一个只和自己聊天的App-设想展示.html)。它内嵌画面、图片和音轨，可独立保存、离线观看。

短片时长 1 分 48 秒，无旁白。画面由浏览器实时绘制，不使用视频文件或视频流；配乐与音效随文件提供。

## 下载包

- [完整网页与短片](downloads/项目设想网页-含短片.zip)：解压后打开 `index.html`。
- [短片源码与离线入口](downloads/设想展示短片-源码.zip)：解压后可查看短片及音效制作源码。

## 目录

- `web/`：原生 HTML、CSS、JavaScript 网页及完整播放器。
- `film-production/`：音效制作、混音脚本与时间轴数据。
- `docs/`：网页与短片的制作、结构说明。
- `downloads/`：离线单文件与压缩包。
